# Genius-Square-Solver

I played the Genius Square game a while ago, and I wondered how it could be solved using computation.

Genius Square is a logical problem solving game, where two users compete to be the first to fill a 6x6 board that has blocking pieces (position decided by dice rolls) with a range of shapes. Depending on the blocking pieces, some puzzles can be easy, with many solutions, others may have very few. The game advertises 62,208 different puzzles, all of which have a solution. I want to verify this, and see just how many solutions there are, and also how quickly an algorithm can solve this game.
